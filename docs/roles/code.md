# Code Agent

Input: reviewed component code and category blueprint. Implement a self-contained
category generator using the SDK. Separate seeded free choices, dependent parameter
resolution and assembly. Preserve source provenance. Expose the registered builder,
sampler, author tests, declared domain and authored corner cases. Ensure every
declared design has an implemented code path and produces meaningful variation.
Test part connectivity, joint attachment and the configurations that stress them.
Runtime must not call a model or load source-record Python programs or blueprints.

Output: generator implementation and diagnostics from `rfwa check`.
