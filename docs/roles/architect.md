# Architect Agent

Input: category prompt and reviewed source map. Construct the category blueprint:
component roles and designs, optional/repeated components, independent parameters,
dependent dimensions and placements, interfaces, attachment and joint rules.
Preserve recognizable category structure across choices. State units and bounds;
identify numerical boundaries and coupled combinations that require corner tests.
Keep the blueprint a design artifact rather than a container of copied code.

Output: validated `TemplateDesign` JSON and explicit instructions for the Code Agent.
