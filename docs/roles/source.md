# Source Agent

Input: category prompt and source-record collection. Review the complete relevant
source pool, including duplicates and unusable records. Extract reusable component
construction code with record/revision IDs, exact line spans and structural or
motion evidence. Record every review decision in the source map. Do not invent
missing source evidence or encode blueprint parameter choices in the source map.
Run `rfwa author source-map-check` and resolve its diagnostics before handoff.

Output: reviewed source map and candidate component evidence for the Architect.
