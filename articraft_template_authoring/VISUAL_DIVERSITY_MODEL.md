# Template diversity accounting

本文只定义模板结构多样性的统计口径，不要求渲染，也不设组合数量门槛。

## 槽位

槽位代表可替换的结构或功能组件。一个 candidate 应当至少改变以下一项：

- part tree 或主要几何形态；
- joint 数量、类型、轴或拓扑；
- 组件的装配接口或功能语义。

候选不要求新增或改变关节。若固定同一宿主后，某个槽位产生可辨识的几何外观变化
（例如实心轮与辐条轮、不同料斗轮廓、开口槽与实体端部），即可作为结构候选。
只换颜色、材质、贴图、小幅统一尺寸或不改变主要轮廓的表面装饰仍不单独成为 candidate。

## core/raw

- `core_domain`：所有非 N 结构槽位的完整笛卡尔积。
- `raw_domain`：在 core 的基础上包含 N multiplicity 取值的完整笛卡尔积。
- `multiplicity`：分别报告每个 N 的允许范围和 corner 覆盖。

调色板、连续尺寸、表面细节和装饰密度不计入 core/raw。N 不能用来夸大
core。管线只报告这些数字，不因数字太小自动失败。

## 完整组合原则

`TemplateDomain` 不提供 compatibility gate。声明为独立槽位的候选必须可以完整组合；
参数派生、接口适配、宿主尺寸调整和局部过渡结构负责消除轮廓、容量与支承差异。

例如方形柜身与扇形顶板组合时，柜身应派生与顶板 footprint 对应的弧形过渡肩或顶框，
而不是排除该组合。如果某个候选必须改变整个宿主拓扑，说明它不是独立组件候选，应与
宿主合并为一个结构家族槽位。

轮廓差异大、运动风险高或容量处于边界的组合通过命名 `TEMPLATE_CORNERS` 和作者测试验证，
不从 core/raw 中删除。
